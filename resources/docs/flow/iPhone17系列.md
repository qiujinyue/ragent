# iPhone 17 系列

## 产品定位

iPhone 17 系列于 2025 年 9 月发布，全系搭载 A19/A19 Pro 芯片，标准版首次支持高刷新率。该系列包含四款机型：iPhone 17、iPhone 17 Air（超薄款）、iPhone 17 Pro 和 iPhone 17 Pro Max。这是苹果首次在标准版 iPhone 上提供 ProMotion 120Hz 显示屏。

---

## iPhone 17

### 产品介绍

iPhone 17 是标准版旗舰，首次配备 6.3 英寸 ProMotion OLED 显示屏，支持 120Hz 自适应刷新率。搭载 A19 芯片，后置双摄系统升级为 4800 万像素主摄 + 4800 万像素超广角组合。前置摄像头升级至 2400 万像素，支持人像模式和深度控制。

### 规格参数

| 类别 | 参数 |
|------|------|
| 芯片 | A19 芯片（6 核 CPU + 5 核 GPU + 16 核神经网络引擎） |
| 显示屏 | 6.3 英寸 Super Retina XDR，2622 x 1206 分辨率，460 ppi，ProMotion 120Hz |
| 存储容量 | 128GB / 256GB / 512GB |
| 后置摄像头 | 4800 万像素主摄（f/1.6）+ 4800 万像素超广角（f/2.2） |
| 前置摄像头 | 2400 万像素原深感摄像头（f/1.9） |
| 电池容量 | 3747 mAh（视频播放最长 24 小时） |
| 防水等级 | IP68（6 米水深最长 30 分钟） |
| 重量 | 177 克 |
| 尺寸 | 150.7 x 72.4 x 7.3 mm |
| 接口 | USB-C（USB 3，最高 10Gb/s） |
| 特殊按键 | 操作按钮 + 相机控制按钮 |

## iPhone 17 Air

## 系列共同特性

- A19/A19 Pro 芯片（全系 3nm 工艺）
- 操作按钮 + 相机控制按钮（全系标配）
- 2400 万像素前置摄像头（全系升级）
- USB-C 接口（标准版 USB 3，Pro 版 USB 4）
- 卫星紧急 SOS 求救功能
- 车祸检测功能
- Apple Intelligence 增强版支持
- iOS 19 系统（出厂预装）

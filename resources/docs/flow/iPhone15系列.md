# iPhone 15 系列

## 产品定位

iPhone 15 系列于 2023 年 9 月发布，首次在标准版上引入灵动岛设计，标配 USB-C 接口，搭载 48MP 主摄。该系列包含四款机型：iPhone 15、iPhone 15 Plus、iPhone 15 Pro 和 iPhone 15 Pro Max。

---

## iPhone 15

### 产品介绍

iPhone 15 是苹果入门级旗舰手机，采用融色玻璃背板设计，配备 6.1 英寸 Super Retina XDR 显示屏，峰值亮度达 2000 尼特。搭载 A16 仿生芯片，配备 48MP 主摄，支持 2 倍光学变焦。首次采用 USB-C 接口，支持 USB 2 传输。

### 规格参数

| 类别 | 参数 |
|------|------|
| 芯片 | A16 仿生芯片（6 核 CPU + 5 核 GPU + 16 核神经网络引擎） |
| 显示屏 | 6.1 英寸 Super Retina XDR，2556 x 1179 分辨率，460 ppi |
| 存储容量 | 128GB / 256GB / 512GB |
| 后置摄像头 | 4800 万像素主摄（f/1.78）+ 1200 万像素超广角（f/2.4） |
| 前置摄像头 | 1200 万像素原深感摄像头（f/1.9） |
| 电池容量 | 3349 mAh（视频播放最长 20 小时） |
| 防水等级 | IP68（6 米水深最长 30 分钟） |
| 重量 | 171 克 |
| 尺寸 | 147.6 x 71.6 x 7.8 mm |

## iPhone 15 Pro

### 产品介绍

iPhone 15 Pro 是专业旗舰手机，率先采用钛金属边框和 A17 Pro 芯片。配备可自定义操作的 Action 按键，支持 ProMotion 120Hz 自适应刷新率，搭载雷雳 3 接口。专业级摄像头系统支持 Log 模式视频拍摄和学院色彩编码系统（ACES）。

### 规格参数

| 类别 | 参数 |

| 前置摄像头 | 1200 万像素原深感摄像头（f/1.9） |
| 电池容量 | 3274 mAh（视频播放最长 23 小时） |
| 防水等级 | IP68（6 米水深最长 30 分钟） |

## 系列共同特性

- 灵动岛设计（全系标配）
- USB-C 接口（全系标配）
- 4800 万像素主摄（Pro 系列支持 ProRAW）
- 卫星紧急 SOS 求救功能
- 车祸检测功能
- iOS 17 系统（出厂预装）

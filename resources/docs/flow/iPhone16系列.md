# iPhone 16 系列

## 产品定位

iPhone 16 系列于 2024 年 9 月发布，搭载 A18/A18 Pro 芯片，全系新增相机控制按钮和拍照键。该系列首次在标准版和 Pro 版本上实现芯片代际差距缩小，但屏幕刷新率仍有明显区分。iPhone 16 系列包含四款机型：iPhone 16、iPhone 16 Plus、iPhone 16 Pro 和 iPhone 16 Pro Max。

---

## iPhone 16

### 产品介绍

iPhone 16 是标准版旗舰，搭载 A18 芯片，采用全新设计的后置摄像头布局（垂直排列），支持微距拍摄和空间照片录制。新增相机控制按钮和动作按钮，屏幕尺寸维持 6.1 英寸，首次支持 45W 有线快充。

### 规格参数

| 类别 | 参数 |
|------|------|
| 芯片 | A18 芯片（6 核 CPU + 5 核 GPU + 16 核神经网络引擎） |
| 显示屏 | 6.1 英寸 Super Retina XDR，2556 x 1179 分辨率，460 ppi |
| 存储容量 | 128GB / 256GB / 512GB |
| 后置摄像头 | 4800 万像素主摄（f/1.6）+ 1200 万像素超广角（f/2.2），支持微距摄影 |
| 前置摄像头 | 1200 万像素原深感摄像头（f/1.9） |
| 电池容量 | 3561 mAh（视频播放最长 22 小时） |
| 防水等级 | IP68（6 米水深最长 30 分钟） |
| 重量 | 170 克 |
| 尺寸 | 147.6 x 71.6 x 7.8 mm |
| 接口 | USB-C（USB 2，最高 480Mb/s） |
| 特殊按键 | 操作按钮（可自定义快捷功能）+ 相机控制按钮 |

### 中国特供信息

- 双卡双待（nano-SIM + eSIM）
- 支持中国移动、联通、电信、广电 5G 网络
- 微信分身支持
- 支持北斗卫星导航

## iPhone 16 Pro

### 产品介绍

iPhone 16 Pro 是专业旗舰，搭载 A18 Pro 芯片，配备 6.3 英寸显示屏（比上代更大）。支持 ProMotion 120Hz 自适应刷新率，全新 4800 万像素超广角摄像头支持微距摄影和 4K 120fps 杜比视界视频拍摄。新增相机控制按钮，提供专业级拍摄体验。

## 系列共同特性

- 全新垂直后置摄像头排列
- 操作按钮（可自定义快捷功能）
- 相机控制按钮（全系标配）
- USB-C 接口（标准版 USB 2，Pro 版 USB 3）
- 卫星紧急 SOS 求救功能
- 车祸检测功能
- Apple Intelligence（苹果智能）支持
- iOS 18 系统（出厂预装）

# 简单分块模式的文档入库

## 概述

简单分块模式（CHUNK）是 Ragent 系统中文档处理的两种模式之一（另一种为 PIPELINE 模式）。该模式适用于标准文档的分块入库，执行 `Extract → Chunk → Embed → Persist` 四阶段处理流程。

## 入口链路

```
用户请求 (POST /knowledge-base/docs/{docId}/chunk)
        │
        ▼
KnowledgeDocumentController.startChunk()
        │
        ▼
发送 RocketMQ 事务消息
        │
        ▼
KnowledgeDocumentChunkConsumer.onMessage()
        │
        ▼
runChunkTask()  ◀─────────────┐
        │                       │
        ├── 选择处理模式 ────────┘
        │   │
        │   └── ProcessMode.CHUNK → runChunkProcess()
        │
        ▼
persistChunksAndVectorsAtomically()
        │
        ▼
更新文档状态为 SUCCESS / FAILED
```

## 核心流程详解

### 1. 任务初始化 (runChunkTask)

**文件**: `bootstrap/.../knowledge/service/impl/KnowledgeDocumentServiceImpl.java:202`

```java
private void runChunkTask(KnowledgeDocumentDO documentDO) {
    // 1. 创建分块日志记录
    KnowledgeDocumentChunkLogDO chunkLog = KnowledgeDocumentChunkLogDO.builder()
            .docId(docId)
            .status(DocumentStatus.RUNNING.getCode())
            .processMode(processMode.getValue())
            .chunkStrategy(documentDO.getChunkStrategy())
            .pipelineId(documentDO.getPipelineId())
            .startTime(new Date())
            .build();
    chunkLogMapper.insert(chunkLog);

    // 2. 根据处理模式选择执行路径
    if (ProcessMode.PIPELINE == processMode) {
        chunkResults = runPipelineProcess(documentDO);
    } else {
        ChunkProcessResult result = runChunkProcess(documentDO);  // ← 简单分块模式
        extractDuration = result.extractDuration();
        chunkDuration = result.chunkDuration();
        embedDuration = result.embedDuration();
        chunkResults = result.chunks();
    }

    // 3. 持久化 chunks 和向量
    persistChunksAndVectorsAtomically(collectionName, docId, chunkResults);
}
```

```java
public String extractText(InputStream stream, String fileName) {
    try {
        // 使用 Apache Tika 将 PDF/Word/Excel/PPT 等格式解析为纯文本
        String text = TIKA.parseToString(stream);
        // 文本清洗：移除控制符、多余空白等
        return TextCleanupUtil.cleanup(text);
    } catch (Exception e) {
        throw new ServiceException("解析文件失败: " + fileName);
    }
}
```

**支持的格式**: PDF、Word、Excel、PPT、HTML、XML 等（由 Apache Tika 自动识别）

### 3. 文本分块 (Chunk)

**调用链路**:
```
runChunkProcess()
    │
    ▼
chunkingStrategyFactory.requireStrategy(chunkingMode)  → 获取分块策略
    │
    ▼
chunkingStrategy.chunk(text, config)  → 执行分块
    │
    ▼
StructureAwareTextChunker.chunk()  → 结构感知分块
```

**文件**: `bootstrap/.../core/chunk/strategy/StructureAwareTextChunker.java:57`

**分块策略**:
| 块类型 | 识别规则 | 示例 |
|-------|---------|------|
| HEADING | `#` 开头 | `## 标题` |
| CODE | ` ``` ` 围栏 | 代码块 |
| ATOMIC | 单行图片/链接 | `![img](url)` |
| PARA | 普通段落 | 文本段落 |

**分块规则**:
- 只在块边界切分，**绝不改写原文**
- 通过 `min/target/max` 控制单个 chunk 大小
- 支持可选的 overlap（复制上一 chunk 尾部到当前 chunk 开头）

### 6. 向量库写入 (PgVectorStoreService)

**文件**: `bootstrap/.../rag/core/vector/PgVectorStoreService.java:42`

```java
public void indexDocumentChunks(String collectionName, String docId, List<VectorChunk> chunks) {
    jdbcTemplate.batchUpdate(
        "INSERT INTO t_knowledge_vector (id, content, metadata, embedding) " +
        "VALUES (?, ?, ?::jsonb, ?::vector)",
        chunks, chunks.size(), (ps, chunk) -> {
            ps.setString(1, chunk.getChunkId());
            ps.setString(2, chunk.getContent());
            ps.setString(3, buildMetadataJson(collectionName, docId, chunk));
            ps.setString(4, toVectorLiteral(chunk.getEmbedding())); // float[] → "[0.1,0.2,...]"
        });
}
```

**向量表结构** (`t_knowledge_vector`):
| 字段 | 类型 | 说明 |
|-----|------|------|
| id | varchar | chunk 唯一ID (snowflake) |
| content | text | chunk 原文内容 |
| metadata | jsonb | 扩展元数据 (collection_name, doc_id, chunk_index) |
| embedding | vector | 向量 (维度如 1024/4096) |

## 配置参数

分块策略参数（`TextBoundaryOptions`）:

| 参数 | 说明 | 默认值 |
|-----|------|-------|
| `minChars` | chunk 最小字符数 | 50 |
| `targetChars` | chunk 目标字符数 | 500 |
| `maxChars` | chunk 最大字符数 | 1000 |
| `overlapChars` | 相邻 chunk 重叠字符数 | 0 |

Embedding 模型配置（`application.yaml`）:

```yaml
ai:
  providers:
    siliconflow:
      api-key: ${SILICON_FLOW_API_KEY}
      base-url: https://api.siliconflow.cn
    ollama:
      base-url: http://localhost:11434
  selection:
    embedding:
      candidates:
        - provider: siliconflow
          model: thenlper/gte-Qwen3-8B
          dimension: 1024
```

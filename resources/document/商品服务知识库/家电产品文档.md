## 1. 用户手册规范

### 1.1 功能说明

#### 1.1.1 产品功能模块说明

家电产品功能说明应遵循「功能名称→功能原理→适用场景→操作步骤→使用效果」的规范格式。

**空调产品功能说明示例：**

```
【制冷功能】
功能原理：
  制冷循环系统由压缩机、冷凝器、节流装置、蒸发器四大部件组成。
  制冷剂在压缩机内被压缩成高温高压气体，进入冷凝器散热后变成常温高压液体，
  经节流装置降压后进入蒸发器蒸发吸热，从而降低室内温度。

适用场景：
  - 夏季室温高于26°C时使用
  - 房间面积与空调匹数匹配（1匹适用10-15㎡）
  - 密闭空间效果更佳

操作步骤：
  1. 遥控器对准空调，按下「开/关」键开机
  2. 按「模式」键选择「制冷」模式（雪花图标）
  3. 按「温度+」「温度-」设定目标温度（建议26°C）
  4. 按「风速」调节风力大小（自动/低/中/高）
  5. 按「风向」调节出风口方向

使用效果：
  - 开机后5-10分钟开始有明显凉感
  - 达到设定温度后进入恒温运行
  - 耗电量与设定温度差、环境温度相关
```

**洗衣机产品功能说明示例：**

```
【洗涤模式说明】

| 洗涤模式 | 适用衣物 | 水温 | 洗涤时间 | 转速 |
|---------|---------|------|---------|------|
| 标准洗 | 棉麻衣物、日常穿着 | 30-40°C | 45-60min | 800-1000 |
| 快洗15 | 少量轻度脏污衣物 | 常温 | 15min | 600 |
| 强力洗 | 厚重大件（床单、窗帘） | 60°C | 90-120min | 1200 |
| 羊毛洗 | 羊毛、丝织物 | 30°C | 40-50min | 400 |
| 筒自洁 | 内筒清洁 | 90°C | 60-90min | 1200 |
| 脱水 | 单独脱水程序 | - | 5-10min | 1200 |

特殊功能说明：
  - 预约洗涤：可设置2-24小时后的启动时间
  - 童锁：同时长按「温度」+「转速」3秒启用
  - 中途添衣：暂停后可打开门盖添加衣物（部分机型支持）
```

#### 1.1.2 智能家电联网配置

```
【智能家电联网配置指南】

配置前提：
  - 家电设备支持Wi-Fi/蓝牙连接
  - 智能手机安装对应APP（如「XX智慧家」）
  - 网络环境：2.4GHz Wi-Fi（部分支持5GHz）

配置步骤（以空调为例）：
  步骤1：下载安装APP
    - 应用商店搜索「XX智慧家」
    - 注册并登录账号

  步骤2：添加设备
    - 打开APP，点击「添加设备」
    - APP自动搜索附近设备，或手动选择「空调」品类

  步骤3：进入配网模式
    - 空调遥控器对准，按「Wi-Fi」键3秒
    - 显示屏出现「Wi-Fi」图标闪烁
    - 部分机型：关机状态下同时按「强劲」+「静音」键

  步骤4：连接网络
    - APP显示发现的设备
    - 输入家庭Wi-Fi密码
    - 等待配网成功（约30秒）

  步骤5：使用控制
    - 配网成功后显示设备在线
    - 可远程开关机、调节温度、查看用电量等

常见问题：
  - 配网失败：确认Wi-Fi为2.4GHz频段，密码正确
  - 设备离线：重启家电和路由器，重新配网
  - 不支持5GHz Wi-Fi：请使用2.4GHz网络
```

### 1.3 设置向导

#### 1.3.1 空调安装与首次使用设置

```
【空调安装与首次使用设置向导】

【第一步：安装位置选择】
  ✓ 挂机安装高度：离顶面≥15cm，离墙面10-15cm
  ✓ 室外机安装：通风良好，避免阳光直射
  ✓ 室内机与墙壁保持一定角度（利于冷凝水排出）
  ✓ 避免安装位置：热源上方、强磁场处、腐蚀性气体环境

【第二步：抽真空操作】（变频空调必须）
  1. 连接冷媒管道与室内机
  2. 连接真空泵，抽真空15-30分钟
  3. 确认压力表指针指向-1（约-0.1MPa）
  4. 确认无泄漏后打开阀门充注冷媒
  注意：此操作由安装人员完成

【第三步：试运行检查】
  1. 开启制冷模式，温度设定16°C
  2. 确认出风口有冷风（5分钟内明显凉感）
  3. 确认无异常噪音或振动
  4. 检查室内机底部是否漏水
  5. 切换至制热模式（如支持），确认制热正常

【第四步：基础设置】
  1. 遥控器电池安装（注意正负极）
  2. 设定当前时间（遥控器时钟键）
  3. 设置定时开关机（如需要）
  4. 开启电辅热（冬季寒冷地区）
```

#### 1.3.2 冰箱首次使用设置

```
【冰箱首次使用设置向导】

【第一步：搬运与安置】
  1. 搬运后静置2-4小时再通电（让冷冻油回流）
  2. 放置于通风干燥处，与墙壁保持≥10cm距离
  3. 调整底部水平脚，使冰箱平稳无晃动
  4. 避免阳光直射，远离热源

【第二步：温度设定】
  ┌─────────────────────────────────────────────────┐
  │  冷藏室温度设定：3-5°C（日常使用推荐4°C）       │
  │  冷冻室温度设定：-18°C以下（日常使用推荐-18°C） │
  │  变温室设定：根据食材调整（推荐0°C保鲜模式）    │
  └─────────────────────────────────────────────────┘

【第三步：智能功能设置】（如为智能冰箱）
  1. 连接Wi-Fi，下载「XX智家」APP
  2. 扫码绑定冰箱设备
  3. 设置食材管理提醒
  4. 开启假日模式（外出时节能）

【第四步：放置食材】
  ✓ 冷藏室：蔬菜、水果、饮料、剩菜
  ✓ 冷冻室：肉类、海鲜、冰激凌、冷冻食品
  ✓ 门板储物：调味品、饮料、酱料
  ✓ 注意事项：留出通风空间，不要塞太满
```

### 1.4 故障排除

#### 1.4.1 空调常见故障排查

| 故障现象 | 可能原因 | 排查步骤 | 解决建议 |
|---------|---------|---------|---------|
| 空调不启动 | 停电/电源问题 | 检查插座是否有电 | 等待供电恢复/检查插座 |
| | 遥控器电池没电 | 遥控器无显示 | 更换电池（AAA 1.5V） |
| | 保护模式启动 | 电压不稳/过流保护 | 断电5分钟后重新启动 |
| 空调不制冷/不制热 | 模式设置错误 | 确认制冷/制热模式 | 切换正确模式 |
| | 温度设定不当 | 制冷温度高于室温 | 设定温度低于室温 |
| | 过滤网堵塞 | 过滤网积灰 | 清洗过滤网，晾干后装回 |
| | 冷媒不足 | 使用多年后 | 联系售后加注冷媒 |
| 空调有异味 | 内部潮湿发霉 | 长时间未使用 | 开送风模式通风30分钟 |
| | 异味来源不明 | 室内空气问题 | 使用空气净化功能 |
| 空调噪音大 | 出风口异物 | 检查导风板 | 清除异物 |
| | 安装不水平 | 支架松动 | 联系安装人员调整 |
| | 共振问题 | 管路与墙壁接触 | 加装防振垫 |
| 空调漏水 | 室内机结冰 | 制冷剂不足/过滤网堵 | 清洗过滤网，必要时加冷媒 |
| | 排水管堵塞 | 赃物堵塞 | 疏通排水管 |
| | 安装倾斜 | 室内机不水平 | 调整安装角度 |

| 故障现象 | 可能原因 | 排查步骤 | 解决建议 |

| | 洗衣机未调平 | 四角不平稳 | 调整底部水平脚 |
| | 共振 | 转速过高 | 选择较低转速 |

| | 洗衣粉类型不对 | 高泡型不适合 | 使用低泡洗衣粉/液 |

| | 排水管破裂 | 老化/被异物划破 | 更换排水管 |
| | 进水管接头松动 | 未拧紧 | 重新连接并拧紧 |

| 冷冻室制冷效果差 | 除霜异常 | 霜层过厚 | 手动除霜或自动除霜 |

### 1.5 保养维护建议

#### 1.5.1 空调保养维护

```
【日常清洁保养】

过滤网清洗（每月一次）：
  步骤1：关闭电源，打开室内机进风口面板
  步骤2：抽出过滤网（部分机型需双手操作）
  步骤3：用清水冲洗过滤网，配合软刷轻轻刷洗
  步骤4：阴凉通风处晾干（避免阳光暴晒）
  步骤5：装回过滤网，关闭面板
  注意：勿用热水、洗衣粉等清洗剂

室内机清洁（每季度一次）：
  ✓ 外壳用干布擦拭，避免使用酒精等有机溶剂
  ✓ 出风口用软毛刷清理灰尘
  ✓ 遥控器显示屏用干布轻轻擦拭

室外机清洁（每年一次，建议专业人员）：
  ✓ 清理风扇叶片上的灰尘杂物
  ✓ 检查散热片是否堵塞
  ✓ 确认支架稳固，无松动锈蚀

【换季保养】

夏季使用前：
  1. 检查遥控器电池
  2. 清洗过滤网
  3. 开启送风模式运行30分钟
  4. 确认制冷效果正常

冬季制热前：
  1. 检查过滤网
  2. 开启制热模式预热
  3. 检查电辅热功能是否正常
  4. 长时间不使用建议拔掉电源

【使用注意事项】
  ✓ 温度设定建议：制冷26°C，制热22°C
  ✓ 每运行2-4小时开窗通风15分钟
  ✓ 避免长时间连续使用高功率模式
  ✓ 雷雨天气建议关闭空调，断开电源
```

#### 1.5.2 洗衣机保养维护

```
【日常清洁保养】

筒清洁程序（每月一次）：
  步骤1：确认内筒无衣物
  步骤2：倒入洗衣机槽清洁剂（建议使用专用清洁剂）
  步骤3：选择「筒自洁」程序（如无此程序，选95°C高温洗）
  步骤4：运行完整程序
  步骤5：程序结束后打开门通风晾干

门封圈清洁（每次洗完后）：
  ✓ 用干布擦拭门封圈内侧
  ✓ 清除残留绒毛和水渍
  ✓ 保持门盖微开通风（防霉防臭）

洗剂盒清洁（每月一次）：
  ✓ 抽出洗剂盒（按下释放键）

## 2. 安全指南

### 2.1 安全警示

#### 2.1.1 通用电气安全警告

```
┌─────────────────────────────────────────────────────────────┐
│  ⚠️  电气安全警告                                            │
└─────────────────────────────────────────────────────────────┘

【电源要求】
  ▸ 使用额定电压220V/50Hz电源，禁止接入非指定电压
  ▸ 必须使用带有接地线的三孔插座
  ▸ 禁止使用拖线板同时连接多个大功率电器
  ▸ 电源线损坏必须使用原装配件更换，禁止自行接线

【防水防潮】
  ▸ 禁止在浴室、厨房潮湿环境使用非防水设计的家电
  ▸ 禁止用湿手操作电器开关
  ▸ 空调、洗衣机等需远离水源安装
  ▸ 发现机身进水应立即断电，联系售后处理

【禁止行为】
  ▸ 禁止私自拆卸、维修家电内部部件
  ▸ 禁止在通电状态下进行清洁保养
  ▸ 禁止覆盖运转中的电器（如空调、冰箱）
  ▸ 禁止自行添加或更换制冷剂
  ▸ 禁止改造机器结构或线路

【异常处理】
  ▸ 发现异常声响、异味、冒烟，立即断电停止使用
  ▸ 遇到停电应关闭所有电器开关，来电后逐一开启
  ▸ 雷雨天气建议关闭家电并拔掉电源插头
```

#### 2.1.2 各类家电专项安全警告

```
【空调安全警告】
  ▸ 室外机安装必须由专业人员操作
  ▸ 禁止在空调出风口下长时间站立
  ▸ 制冷运行时，室内温度不宜设定过低（建议≥26°C）
  ▸ 制热运行时，室内温度不宜设定过高（建议≤28°C）
  ▸ 空调运转时禁止打开室内机外壳

【洗衣机安全警告】
  ▸ 洗衣机必须放置平稳，防止运转时晃动
  ▸ 洗涤结束后待内筒停止转动再打开门盖
  ▸ 禁止洗涤易燃衣物（石油类溶剂浸染）
  ▸ 儿童不得单独操作洗衣机
  ▸ 滚筒洗衣机运行时禁止打开门（除非有中途添衣功能）

【冰箱安全警告】
  ▸ 禁止在冰箱内放置易燃、易爆物品
  ▸ 禁止使用锐器除冰（可能刺破制冷管道）
  ▸ 搬运时倾斜角度不得超过45度
  ▸ 长期不使用应拔掉电源，清空内部

【热水器安全警告】
  ▸ 必须安装漏电保护开关
  ▸ 定期检查接地线是否正常
  ▸ 燃气热水器必须保证通风良好
  ▸ 禁止在浴室封闭环境使用燃气热水器
  ▸ 定期检查燃气管路是否泄漏

【油烟机安全警告】
  ▸ 使用前确认排烟管道畅通
  ▸ 禁止用油烟机直接排放火锅、烧烤油烟
  ▸ 清洁前必须断电，等待扇叶完全停止
  ▸ 滤网、油杯需定期清理（油污为易燃物）
```

## 6. 常见问题解答规范

### 6.1 安装问题

#### 6.1.1 空调安装FAQ

```
Q1：空调安装高度有什么要求？
A：壁挂式空调室内机安装高度建议：
   - 距离天花板：≥15cm（利于回风）
   - 距离墙面：10-15cm（减少共振）
   - 底部离地面：2.2-2.5m（最佳舒适区）
   - 距左侧墙壁：≥15cm（留出维修空间）
   注意：安装高度影响制冷/制热效果和舒适度

Q2：空调室外机安装位置有什么要求？
A：室外机安装要求：
   ✓ 通风良好，远离热源和油烟
   ✓ 避免阳光直射，可加装遮阳棚
   ✓ 距墙≥10cm，保证散热空间
   ✓ 噪音不扰民（避免正对邻居窗户）
   ✓ 便于日后维修操作
   ✓ 支架安装必须牢固，承重≥150kg

Q3：空调安装需要抽真空吗？
A：是的，变频空调必须抽真空：
   - 目的：排除系统内空气和水分
   - 时间：抽真空15-30分钟
   - 压力：真空度应达-0.1MPa
   - 注意：此操作必须由专业安装人员完成
   警告：不抽真空直接加冷媒会影响制冷效果，缩短压缩机寿命

Q4：空调安装收费吗？
A：安装收费说明：
   - 基础安装：免费（限指定范围内）
     含：打孔（1个）、挂墙安装、连接管连接
   - 收费项目（超出部分）：
     | 项目 | 参考价格 |
     | 铜管加长 | ¥80-120/米 |
     | 排水管加长 | ¥30-50/米 |
     | 墙壁打孔（钢筋混凝土） | ¥80-150/个 |
     | 高空作业（4楼以上） | ¥100-200/台 |
     | 拆旧机 | ¥100-150/台 |

Q5：空调可以安装在浴室吗？
A：不可以，原因如下：
   ✗ 非防水设计，内部元器件会受潮损坏
   ✗ 浴室水汽进入机器影响电气安全
   ✗ 冷凝水可能损坏墙壁和机器
   建议：浴室如需取暖，选择浴霸或暖风机
```

#### 6.1.2 冰箱/洗衣机安装FAQ

```
Q6：冰箱应该放置在什么位置？
A：冰箱放置要求：
   ✓ 通风良好，背部散热需距墙≥10cm
   ✓ 避免阳光直射，远离热源（灶台、暖气）
   ✓ 地面平整，承重≥200kg
   ✓ 预留足够空间（两侧各5cm，后侧10cm）
   ✓ 环境温度：10°C-43°C（亚温带至热带）

Q7：新冰箱到家后需要静置吗？
A：需要，这是重要的注意事项：
   - 原因：运输中压缩机机油可能流出
   - 方法：静置2-4小时（越久越好）
   - 要求：保持直立，不要倾斜
   - 通电前检查：门是否可以正常开合
   注意：未经静置直接通电可能损坏压缩机

Q8：洗衣机安装需要注意什么？
A：滚筒洗衣机安装要点：
   1. 地面必须平整坚硬（承重≥200kg）
   2. 使用水平仪调整脚垫，确保水平
   3. 连接进水管（水压0.03-1MPa）
   4. 连接排水管（高度40-100cm）
   5. 插座必须接地，使用漏电保护
   6. 首次使用建议运行筒自洁程序

Q9：波轮洗衣机和滚筒洗衣机安装有何不同？
A：主要差异：
   ┌────────────────┬────────────────┬────────────────┐
   │ 项目           │ 波轮式         │ 滚筒式         │
   ├────────────────┼────────────────┼────────────────┤
   │ 地面要求       │ 平整即可       │ 必须水平       │
   │ 进水要求       │ 高度无要求     │ 建议高度0.6-1m│
   │ 排水要求       │ 可直接接地漏   │ 必须架高       │
   │ 减震要求       │ 低             │ 高（高转速）   │
   │ 底部固定       │ 无需固定       │ 需固定防振     │
   └────────────────┴────────────────┴────────────────┘
```

### 6.2 使用问题

#### 6.2.1 空调使用FAQ

```
Q10：空调应该开多少度最合适？
A：温度设置建议：
   - 制冷模式：26°C最为节能，人体感觉舒适
   - 每调低1°C，多耗电约7%
   - 夏季室内外温差≤8°C不易感冒
   - 睡眠时使用睡眠模式，可自动调节

Q11：空调多久需要加一次冷媒？
A：正常情况下，空调不需要定期加冷媒：
   ✓ 冷媒在密闭系统内循环，不会消耗
   ✓ 如发现不制冷，可能是泄漏
   ✓ 泄漏征兆：制冷效果差、室外机结霜
   ✓ 发现泄漏必须先修漏再补冷媒
   注意：非专业人员禁止操作制冷剂

Q12：空调长时间不用需要注意什么？
A：换季停机保养：
   1. 关机前先开送风模式运行2小时，干燥内部
   2. 关闭电源开关，拔掉插头
   3. 取出遥控器电池
   4. 清洗过滤网，晾干后装回
   5. 给室外机加装防护罩（可选）
   6. 来年使用前先开送风确认无异味

Q13：变频空调和定频空调哪个更省电？

   ┌────────────────┬────────────────┬────────────────┐

   │ 初始成本       │ 较高           │ 较低           │

#### 6.2.2 冰箱使用FAQ

```
Q14：冰箱温度怎么调？
A：温度调节方法：
   机械温控（旋钮式）：
     - 旋钮通常1-7档，数字越大温度越低
     - 夏季建议2-3档，冬季建议4-5档
     - 避免长时间调最高档（压缩机不停机）
   
   电子温控（按键式）：
     - 冷藏室：3-5°C
     - 冷冻室：-18°C
     - 变温室：根据需要设置

Q15：冰箱结冰怎么办？
A：结冰原因及处理：
   【直冷冰箱结冰】
     原因：门封不严、温控器档位太高
     处理：断电除冰，调整温控档位
   
   【风冷冰箱结冰】
     原因：化霜传感器故障、排水口堵塞
     处理：疏通排水口，联系售后检修
   
   预防措施：
     ✓ 热食物先冷却再放入
     ✓ 开门时间尽量短
     ✓ 门封条定期检查密封性

Q16：冰箱噪音大正常吗？
A：冰箱噪音来源及判断：
   正常噪音：
     - 压缩机运转声：低沉的嗡嗡声
     - 制冷剂流动声：轻微的咕噜声
     - 风扇运转声：均匀的气流声
   
   异常噪音（需检查）：
     - 金属撞击声：物体进入压缩机舱
     - 咕噜声增大：制冷剂量异常
     - 振动声大：冰箱未放平稳
   
   降低噪音方法：
     ✓ 调整底部水平脚
     ✓ 冰箱背部离墙≥10cm
     ✓ 避免共振（不要贴墙放置）
```

### 6.3 故障问题

#### 6.3.1 空调故障FAQ

```
Q17：空调显示故障代码E5是什么意思？
A：E5代码因品牌而异，常见含义：
   - 格力E5：低压保护
   - 美的E5：室外机温度传感器故障
   - 海尔E5：压缩机过流保护
   
   处理建议：
   1. 关机断电，等待5分钟后重新启动
   2. 检查室外机散热是否良好
   3. 检查过滤网是否堵塞
   4. 如仍出现，联系售后服务

Q18：空调出风口有异味怎么处理？
A：异味原因及处理方法：
   【原因1：潮湿发霉】
     - 长时间制冷后未使用送风干燥
     - 处理：开送风模式运行30分钟
   
   【原因2：滤网脏堵】
     - 灰尘堆积产生异味
     - 处理：清洗过滤网，晾干后装回
   
   【原因3：室内烟味/装修味】
     - 环境气味被吸入
     - 处理：加强通风，使用空气净化器
   
   【原因4：冷凝水积水】
     - 排水不畅导致积水发臭
     - 处理：疏通排水管

Q19：空调不启动怎么办？
A：排查步骤：
   步骤1：检查电源
     - 插座是否有电（用其他电器测试）
     - 电源线是否损坏
     - 插头是否松动
   
   步骤2：检查遥控器
     - 电池是否有电（更换新电池）
     - 遥控器是否对准室内机
     - 尝试手动开关（室内机强制开关）
   
   步骤3：检查保护状态
     - 是否停电
     - 电压是否过低（使用稳压器）
     - 是否处于延时保护状态
   
   步骤4：联系售后
     - 以上均排除后，联系专业维修
```

#### 6.3.2 洗衣机故障FAQ

```
Q20：洗衣机脱水时振动很大怎么办？
A：排查和处理步骤：
   【首要检查：运输螺栓】
     - 新机必须拆除背面4颗运输螺栓
     - 否则内筒无法正常减震，会剧烈晃动
     - 螺栓位置见说明书图示
   
   【衣物问题】
     - 衣物是否分布均匀
     - 衣物是否过量（≤额定容量）
     - 是否有单件大件衣物甩偏
   
   【机器问题】
     - 洗衣机是否水平（调整底部脚）
     - 减震器是否损坏
     - 悬挂弹簧是否变形
   
   【处理方法】
     1. 拆除运输螺栓（最常见原因）
     2. 重新整理衣物均匀分布
     3. 调整水平脚，拧紧固定螺母
     4. 联系售后检查减震系统

Q21：洗衣机不排水怎么办？
A：排查和处理：
   步骤1：检查排水管
     - 排水管是否弯折
     - 排水管高度是否正确（≤10cm）
     - 是否插入地漏太深
   
   步骤2：清理过滤器
     - 洗衣机右下角有排水过滤器
     - 逆时针旋转打开，清理内部杂物
     - 注意：提前备好接水容器
   
   步骤3：检查排水泵
     - 是否有异物卡住（硬币、纽扣等）
     - 泵叶轮是否能转动
     - 排水泵是否损坏
   
   步骤4：联系售后
     - 如以上均正常，可能是排水泵故障
```

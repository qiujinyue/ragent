## 1. 用户手册规范

### 1.1 功能说明

#### 1.1.1 核心功能描述

服装产品核心功能说明应采用「功能名称→功能原理→适用场景→使用效果」的规范格式。

**功能性服装功能说明示例：**

```
【保暖功能】

功能原理：
  采用双层结构设计，外层防风面料阻挡冷空气侵入，
  内层抓绒或羽绒填充锁住热量，形成空气保温层。
  原理等同于羽绒服的绒朵储能效应。

适用场景：
  - 秋冬日常通勤：-5°C至10°C环境
  - 户外运动：徒步、露营、钓鱼等轻户外活动
  - 城市代步：骑行、步行等短时间户外活动

使用效果：
  - 静态保暖：同等克重下保暖性能优于棉质面料
  - 防风性能：有效阻挡4-5级风力
  - 透气性能：运动时可排出多余热气
```

```
【速干功能】

功能原理：
  采用聚酯纤维或尼龙面料，通过异形截面纱线设计，
  将体表汗液快速导离至面料表面，实现水分扩散蒸发。
  Coolmax/HeiQ等专利技术可加速30%以上干燥速度。

适用场景：
  - 高强度运动：跑步、健身、球类运动
  - 户外探险：徒步、登山、溯溪
  - 潮湿环境：梅雨季节、沿海地区

使用效果：
  - 吸湿速度：比纯棉快3-5倍
  - 干燥时间：约30分钟（轻薄款）
  - 抑菌性能：减少细菌滋生导致的汗味
```

```
【防水透气功能】

功能原理：
  采用GORE-TEX/Event等防水透膜面料，
  微孔直径（约0.2μm）远小于水分子（约300μm），
  阻止雨水渗入，同时允许汗蒸气排出。

适用场景：
  - 雨天通勤：中等降雨环境下保持干爽
  - 户外探险：登山、滑雪、穿越等
  - 水上运动：帆船、漂流（短时间涉水）

使用效果：
  - 防水等级：可承受10000-20000mm水柱压力
  - 透气性能：5000-15000g/m²/24h
  - 注意事项：长期高压水冲仍可能渗水
```

#### 1.1.2 特色功能说明

```
【可拆卸两穿设计】

设计说明：
  采用拉链或扣式连接设计，实现外套与内胆分离穿着。
  一件衣服可变换三种穿法：单外套、单内胆、外套+内胆组合。

分步穿着指南：
  步骤1：识别连接结构
    - 外套右侧下摆与内胆左侧下摆各有连接拉链
    - 拉链头位于外套右侧，标识"CONNECT"字样

  步骤2：连接穿着（寒冷环境）
    - 将内胆拉链侧对准外套连接处
    - 从下往上拉合拉链，确保完全咬合
    - 检查袖口、领口连接是否平整

  步骤3：单穿外套（春秋季节）
    - 将内胆完全分离，单独穿着外套
    - 适合15°C-25°C环境

  步骤4：单穿内胆（冬季室内）
    - 内胆可单独作为保暖层穿着
    - 适合8°C-18°C环境或暖气室内

适用环境对照：
  ┌────────────────────────────────────────────────────┐
  │ 穿着方式       │  适用温度    │  场景            │
  ├────────────────────────────────────────────────────┤
  │ 外套+内胆     │  -10°C~10°C │  寒冬户外/通勤   │
  │ 单穿外套      │  5°C~20°C   │  春秋季/室内暖气  │
  │ 单穿内胆      │  0°C~15°C   │  深秋初冬/户外   │
  └────────────────────────────────────────────────────┘
```

### 1.3 穿着指南

#### 1.3.1 两穿外套分步穿着指南

```
【可拆卸两穿外套穿着指南】

【组合穿着步骤】

  步骤1：准备工作
    ├─ 取出内胆和外套，确认配件齐全
    ├─ 检查拉链是否完好，清理拉链异物
    └─ 将内胆平铺，外套平铺备用

  步骤2：连接内胆与外套
    ├─ 找到外套右侧下摆的连接标识
    ├─ 找到内胆左侧下摆的对应连接标识
    ├─ 对齐拉链齿，确保标识点重合
    └─ 将内胆塞入外套连接位置

  步骤3：拉合连接拉链
    ├─ 找到外套连接拉链拉头
    ├─ 从下往上匀速拉合，拉至领口处
    ├─ 检查领口、袖口连接是否平整
    └─ 如有褶皱需重新调整后拉合

  步骤4：检查穿着效果
    ├─ 活动肩臂，确认活动自如
    ├─ 检查内胆是否外露
    └─ 如有不适需重新调整连接

【单穿外套步骤】

  步骤1：解开连接拉链
    ├─ 找到外套右侧下摆连接拉链
    ├─ 从上往下拉开至下摆处
    └─ 将内胆完全分离

  步骤2：单独穿着外套
    ├─ 按正常方式穿着外套
    ├─ 拉合主拉链
    └─ 调整帽子/领口至舒适位置

【洗涤建议】
  - 组合穿着时：建议分开洗涤
  - 外套：可机洗，洗涤温度≤30°C
  - 内胆（抓绒）：建议手洗或轻柔机洗
  - 内胆（羽绒）：建议干洗
```

#### 1.3.2 特殊服装穿着指南

```
【连体工装穿着指南】

适用场景：工厂作业、户外施工、汽修等需要全身防护的工作环境

穿着步骤：
  1. 打开胸前双向拉链及所有口袋拉链
  2. 双腿依次伸入裤腿，向上拉至腰部
  3. 双手伸入袖管，整理肩部位置
  4. 扣合裆部按扣（横向设计，便于如厕）
  5. 从下至上拉合主拉链
  6. 调整袖口、裤脚至舒适位置
  7. 系好腰带（调节松紧）

脱卸步骤：
  1. 先解开腰带
  2. 从上至下拉开主拉链
  3. 解开裆部按扣
  4. 将上半身向前折，双手向后抽出
  5. 弯腰向下，从脚踝处脱下裤腿

注意事项：
  - 连体服不建议在如厕频繁的场合穿着
  - 睡前需完全脱下，避免睡眠不适
  - 选择尺码时注意裆部活动空间
```

### 1.4 故障排除

#### 1.4.1 常见问题与解决方法

| 问题类型 | 现象描述 | 可能原因 | 解决方法 |
|---------|---------|---------|---------|
| 拉链问题 | 拉链卡顿 | 拉链齿有异物/拉链头磨损 | 用石蜡涂抹拉链齿；更换拉链头 |
| | 拉链错位 | 拉链齿未对齐或强行拉扯 | 拆开重拉；检查异物 |
| | 拉链拉不上 | 拉链头损坏或布料褶皱卡住 | 更换拉链；抚平褶皱 |
| 魔术贴问题 | 粘性下降 | 绒面被磨平/灰尘覆盖 | 用细齿梳梳理绒面；清洗去污 |
| | 刺面钩丝损坏 | 尖锐物刮伤 | 更换魔术贴；小心使用 |
| 面料问题 | 起球 | 摩擦导致纤维缠结 | 用去毛球器修剪；选择抗起球面料 |
| | 缩水 | 高温洗涤导致纤维收缩 | 选择预缩面料；冷水洗涤 |
| | 褪色 | 染色牢度不足/阳光直射 | 反面洗涤；避免暴晒 |
| 缝线问题 | 开线 | 缝线断裂/张力过大 | 重新缝补；避开高张力部位 |
| | 跳线 | 缝纫机针距问题 | 返厂维修或更换 |
| 填充问题 | 羽绒钻绒 | 面料密度不足/缝线针孔 | 拍打使羽绒均匀分布；选购高密度面料 |
| | 填充结块 | 洗涤方式不当/羽绒质量 | 手洗轻揉；晾干后拍散 |

#### 1.4.2 家庭处理建议

```
【拉链卡顿家庭处理】

方法1：石蜡法（推荐）
  1. 准备蜡烛或石蜡
  2. 将蜡烛在拉链齿上来回涂抹
  3. 反复拉动拉链数次
  4. 清理多余蜡屑
  效果：可解决80%卡顿问题

方法2：铅笔法
  1. 找一支铅笔（铅笔芯含石墨）
  2. 将铅笔芯粉末撒在拉链齿上
  3. 反复拉动拉链
  效果：临时应急可用

方法3：机油法（不推荐）
  - 食用油、机油可能吸引灰尘
  - 短期有效但会加重后续问题
  - 如必须使用，事后需清理干净
```

```
【羽绒服钻绒家庭处理】

轻微钻绒（5根以内）：
  1. 穿着后拍打使羽绒均匀分布
  2. 用手轻轻按压钻绒孔位
  3. 继续穿着，羽绒会自然回缩

中度钻绒（5-20根）：
  1. 用镊子轻轻拔出外露羽绒
  2. 在钻绒位置轻揉面料
  3. 用指甲轻轻按压针孔
  4. 涂抹少量透明指甲油封住针孔

严重钻绒（20根以上）：
  1. 考虑返厂修补
  2. 或联系专业裁缝加衬里
  3. 洗涤时使用专用洗衣袋
```

## 6. 常见问题解答规范

### 6.1 尺码相关FAQ

```
Q1：如何选择合适的尺码？
A：尺码选择建议：
   1. 测量身体关键数据
      - 身高、体重、胸围、腰围、臀围
   2. 对照尺码表选择
      - 本店尺码为标准尺码，建议按身高体重选择
   3. 考虑版型和个人喜好
      - 修身版：建议选平时穿着尺码
      - 合身版：按尺码表选择
      - 宽松版：可适当选大一号
   
   如仍不确定，欢迎咨询客服，提供身高体重给您推荐

Q2：不同版型的尺码差异大吗？
A：不同版型尺码参考：
   ┌─────────────────────────────────────────────────────┐
   │ 版型     │ 版型特点           │ 尺码建议            │
   ├─────────────────────────────────────────────────────┤
   │ 修身版   │ 贴身剪裁，突显身材  │ 按正常码或选小一码 │
   │ 合身版   │ 标准剪裁，舒适自然  │ 按正常码选择       │
   │ 宽松版   │ 休闲剪裁，舒适活动  │ 可选大一码         │
   │ Oversize │ 超宽松剪裁，时尚感  │ 喜欢宽松可大一码   │
   └─────────────────────────────────────────────────────┘
   注意：面料弹力大小也会影响穿着感受

Q3：裤子的尺码怎么选？腰围和臀围哪个更重要？
A：裤子尺码选择建议：
   1. 腰围是决定性因素
      - 裤子腰围应与实际腰围匹配
      - 试穿时弯腰检测腰部是否合适
   2. 臀围作为参考
      - 大部分裤子臀围设计会留有余量
      - 特殊版型（如紧身牛仔裤）需注意臀围
   3. 如介于两个尺码之间
      - 高腰裤建议选小一码
      - 低腰裤建议选大一码

Q4：外套的尺码怎么选？
A：外套尺码选择要点：
   ✓ 肩宽是最重要参考：肩线应对齐肩膀边缘
   ✓ 胸围需留有余量：内搭衣物需要空间
   ✓ 衣长按需选择：
     - 短款：臀部以上，适合搭配高腰裤
     - 常规款：遮住臀部，适合大多数搭配
     - 长款：到大腿中下部，保暖效果好
   ✓ 袖长：正常应到手碗上方
```

### 6.2 材质相关FAQ

```
Q5：面料会起球吗？如何预防？
A：面料起球说明：
   1. 起球原因：
      - 摩擦导致纤维缠结
      - 化纤面料比天然面料更易起球
      - 洗涤和穿着摩擦都会引起
   
   2. 抗起球面料选择：
      - 棉+聚酯混纺（抗起球处理）
      - 纯棉（起球率低）
      - 针织面料比机织面料更易起球
   
   3. 预防措施：
      - 洗涤时翻面洗涤
      - 使用洗衣袋减少摩擦
      - 避免与粗糙表面摩擦
      - 手洗比机洗起球率低
   
   4. 如已起球：
      - 使用去毛球器修剪
      - 定期清理，保持整洁

Q6：面料会缩水吗？如何避免缩水？
A：缩水问题说明：
   1. 缩水原因：
      - 天然纤维（棉、麻、羊毛）遇水收缩
      - 高温洗涤/烘干会加剧缩水
      - 第一次洗涤缩水最明显
   
   2. 预缩面料选择：
      - 预缩处理棉面料（洗涤后尺寸稳定）
      - 化纤面料基本不缩水
      - 洗水工艺处理的面料（自然皱感）
   
   3. 预防措施：
      - 按洗水标温度洗涤（≤30°C）
      - 避免高温烘干
      - 自然晾干最佳
      - 深色衣物分开洗涤

Q7：面料透气吗？夏天穿会不会热？
A：面料透气性说明：
   1. 透气性排名（从高到低）：
      - 棉质面料：透气性最佳
      - 麻面料：透气性好，但易皱
      - 丝稠面料：透气柔软
      - 竹纤维：透气抑菌
      - 化纤面料：透气性差异大
   
   2. 功能性面料：
      - 运动面料：排汗速干，透气孔设计
      - 冰丝面料：触感凉感，透气舒适
      - 网眼面料：局部透气设计
   
   3. 夏季选择建议：
      - 优选棉质/麻质/竹纤维
      - 避免厚实不透气的涂层面料
      - 选择浅色系减少吸热
```

      - 羊毛/羊绒：需使用羊毛模式或手洗
      - 丝绸：不可机洗
      - 羽绒服：部分可机洗，建议查看说明

Q9：可以烘干吗？如何正确晾晒？
A：烘干与晾晒说明：
   1. 查看洗水标：
      ✓ 烘干图标：可烘干（低温）
      ✗ 不可烘干图标：不可烘干
   
   2. 烘干注意事项：
      - 选择低温烘干
      - 使用烘干球效果更好
      - 避免高温导致缩水变形
      - 部分面料不可烘干
   
   3. 晾晒方法：
      【悬挂晾晒】
        - 适用：外套、西装、长裤
        - 使用宽肩衣架
        - 避免阳光直射（深色衣物）
      
      【平铺晾晒】
        - 适用：毛衣、针织衫
        - 放在晾衣网上
        - 定期翻面
      
      【反面晾晒】
        - 适用：深色衣物
        - 减少褪色

Q10：衣服皱了怎么除皱？
A：除皱方法：
   1. 悬挂除皱：
      - 浴室蒸汽除皱：挂浴室利用蒸汽
      - 自然悬挂：轻微褶皱会自然舒展
   
   2. 熨烫除皱：
      - 按洗水标温度熨烫
      - 熨烫时放湿布或喷水
      - 丝绸/化纤需低温熨烫
   
   3. 去皱喷雾：
      - 喷洒在褶皱处
      - 拉平后晾干
      - 适合外出应急
   
   4. 注意事项：
      - 针织面料不建议熨烫
      - 皮革/涂层面料不可熨烫
      - 熨斗温度不可过高

【非质量问题说明】

  ✗ 穿着痕迹（褶皱、洗涤后）
  ✗ 尺码不合适（个人选择问题）
  ✗ 面料起球（正常穿着磨损）
  ✗ 浅程度褪色（正常洗漆现象）

      - 客服指导自行修复

    【方式2：寄回维修】
      - 需要专业维修的问题
      - 双向免费物流
      - 3-7个工作日完成

    【方式3：换货】
      - 无法维修的问题
      - 同款同色换货
      - 缺货可换其他款式或退款

  步骤4：完成确认
    └─ 客服通知处理结果

【保修凭证要求】
  - 订单截图（显示购买时间和订单号）
  - 商品照片（问题细节处特写）
  - 商品照片（标签处，显示品名、货号）
  - 清晰的问题描述

## 1. 用户手册规范

### 1.1 功能说明

产品功能说明应遵循以下结构，采用「场景→操作→结果」的叙事方式。

#### 1.1.1 核心功能模块

| 功能类别 | 说明内容 | 描述要求 |
|---------|---------|---------|
| 开关机功能 | 电源键位置、长按/短按操作逻辑、指示灯状态 | 说明不同电量下的开关机表现 |
| 连接功能 | 蓝牙配对、Wi-Fi连接、NFC触碰、一碰传 | 说明有效距离、兼容协议版本 |
| 交互功能 | 触控操作、语音指令、手势控制、压感反馈 | 说明识别率、响应延迟、适用场景 |
| 显示功能 | 屏幕亮度调节、色温模式、刷新率设置、息屏显示 | 说明亮度范围、护眼认证、刷新率档位 |
| 音频功能 | 降噪模式、通话增强、空间音频、EQ音效 | 说明降噪深度、支持的音频解码格式 |
| 电源功能 | 充电方式、无线充电、反向充电、节电模式 | 说明充电功率、完整充电时间 |
| 存储功能 | 本地存储扩展、云同步、文件管理 | 说明最大扩展容量、同步机制 |
| 安全功能 | 指纹识别、面部解锁、隐私密码、应用锁 | 说明识别速度、安全等级、容错次数 |

#### 1.1.2 软件功能描述

软件功能应说明功能名称、功能入口、操作步骤和预期效果。以「智能语音助手」为例：

```
功能名称：智能语音助手
功能入口：【设置】→【智能助手】→【语音助手】
操作步骤：
  1. 长按电源键0.5秒唤醒语音助手
  2. 对准麦克风说出语音指令
  3. 说出"小艺小艺"热词唤醒（需在设置中开启）
支持指令示例：
  - "帮我查一下明天北京的天气"
  - "帮我设置下午3点的闹钟"
  - "播放音乐"
  - "打开微信"
预期效果：语音助手识别指令并执行相应操作，识别率≥95%（安静环境下）
```

#### 1.3.2 快速配对连接指南

**蓝牙耳机配对（以Type-C耳机为例）**

```
配对前提：
  - 手机蓝牙功能已开启
  - 耳机电量≥20%
  - 耳机处于配对模式（指示灯蓝白交替闪烁）

操作步骤：
  1. 将耳机插入手机Type-C接口
  2. 手机弹出「是否允许耳机访问」弹窗
  3. 点击「允许」
  4. 等待约3秒，耳机指示灯变为白色常亮
  5. 打开「设置」→「蓝牙」，确认耳机已连接

故障排查：
  - 无法识别：请确认耳机插紧，或重新插拔一次
  - 音质异常：请在设置中切换蓝牙音频解码器（LDAC/AAC/SBC）
  - 通话无声：请确认耳机为通话默认设备
```

### 1.4 故障排除

#### 1.4.1 常见问题与解决方案

| 问题类别 | 现象描述 | 可能原因 | 解决方案 |
|---------|---------|---------|---------|
| 开机异常 | 长按电源键无法开机 | 电量耗尽/系统死机 | 连接充电器充电15分钟后再尝试开机；若仍无法开机，尝试强制重启（电源键+音量下键长按15秒） |
| 充电异常 | 充电慢/不充电 | 充电器功率不足/充电口有异物 | 使用原装充电器；清理充电口灰尘；检查充电线是否损坏 |
| 屏幕异常 | 触摸屏失灵/跳屏 | 屏幕贴膜影响/系统软件故障 | 撕除屏幕贴膜测试；重启设备；进入安全模式排查第三方应用 |
| 声音异常 | 扬声器/听筒无声 | 音量关闭/音频通道被占用 | 调高媒体音量；断开蓝牙设备；清理扬声器防尘网 |
| 网络异常 | Wi-Fi无法连接/掉线 | 路由器问题/系统网络模块故障 | 重启路由器和手机；忘记网络后重新连接；恢复网络设置 |
| 发热异常 | 正常使用发烫 | 高功耗运行/环境温度高/充电发热 | 关闭后台高耗电应用；避免边充电边使用；置于阴凉通风处 |
| 电池异常 | 电量掉电快/虚电 | 电池老化/后台应用耗电 | 开启省电模式；关闭不必要的自启动应用；检测电池健康度 |
| 死机卡顿 | 应用无响应/系统卡死 | 内存不足/应用冲突/系统版本bug | 关闭后台应用；清理存储空间；更新系统版本；恢复出厂设置 |

#### 1.4.3 恢复出厂设置操作

```
【恢复出厂设置】

警告：此操作将清除手机所有数据，执行前请务必备份重要资料！

备份建议（按重要程度排序）：
  1. 联系人 → 导出到SIM卡或云端
  2. 照片/视频 → 备份到电脑或云相册
  3. 微信聊天记录 → 使用电脑端微信备份
  4. 应用数据 → 部分应用支持云端同步

操作路径：
  【设置】→【系统与更新】→【重置】→【恢复出厂设置】

或 recovery模式清除：
  1. 关机状态下，长按「电源键+音量上键」
  2. 进入Recovery模式
  3. 选择「清除数据」→「恢复出厂设置」
  4. 完成后选择「重启系统」

恢复出厂设置后：
  - 所有个人数据将被删除
  - 所有设置将恢复为出厂默认
  - 系统版本为恢复时的最新版本
```

### 1.5 保养维护建议

#### 1.5.1 日常保养指南

```
【屏幕保养】
  ✓ 使用时避免尖锐物体划伤屏幕
  ✓ 建议贴附钢化膜（硬度9H）保护屏幕
  ✓ 避免长时间高亮度显示同一内容（预防烧屏）
  ✓ 使用专用屏幕清洁液和微纤维布擦拭
  ✗ 勿用酒精直接擦拭（可能溶解疏油层）
  ✗ 勿使用纸巾或衣物擦拭（可能留下划痕）

【电池保养】
  ✓ 电量保持在20%-80%区间使用最佳
  ✓ 使用原装充电器和数据线
  ✓ 每月进行一次完整充放电（校准电池容量）
  ✓ 充电时移除手机壳（避免过热）
  ✗ 避免边充电边高功耗使用（发热加速电池老化）
  ✗ 避免在极端温度（<0°C 或 >35°C）环境下使用

【接口保养】
  ✓ 定期使用干燥的软毛刷清理充电口
  ✓ 插拔数据线时注意角度和力度
  ✓ Type-C/Lightning接口避免接触液体
  ✗ 勿使用金属物品清理接口（可能造成短路）
  ✗ 避免接口受潮或进水（腐蚀导致接触不良）

【外观保养】
  ✓ 使用保护壳减少机身划痕和磕碰
  ✓ 避免与钥匙、硬币等硬物同放
  ✓ 定期清洁机身缝隙中的灰尘
  ✓ 长时间不使用时，放置于干燥环境
```

#### 1.5.2 存储空间管理

```
【存储空间优化建议】

查看路径：【设置】→【存储】→【存储空间】

清理建议（按效果排序）：
  1. 清理应用缓存

     - 浏览器：设置→隐私→清除浏览数据
     - 短视频应用：设置→清理缓存
     预计释放：2-10GB

  2. 删除无用照片视频
     - 将重要内容备份后删除原文件
     - 开启「自动清理」：拍摄超过一年的照片视频
     预计释放：视实际情况

  3. 卸载不常用应用
     - 进入设置查看应用使用频率
     - 卸载后数据可从应用商店重新下载
     预计释放：视实际情况

  4. 清理下载文件夹
     - 文件管理→下载→批量删除
     预计释放：视实际情况

  5. 恢复出厂设置（终极方案）
     - 备份全部数据后执行
     预计释放：全部可用空间
```

## 2. 安全指南

### 2.1 安全警示

#### 2.1.1 电气安全警告

```
┌─────────────────────────────────────────────────────────────┐
│  ⚠️  电气安全警告                                            │
└─────────────────────────────────────────────────────────────┘

【高压危险】
  ▸ 请勿自行拆卸电池或设备内部元件
  ▸ 设备内部存在高压电路，非专业人员拆卸可能造成触电
  ▸ 电池损坏（如膨胀、漏液、起火）应立即远离并联系售后

【充电安全】
  ▸ 使用标配充电器，输出电压电流必须与设备要求匹配
  ▸ 禁止使用损坏的充电器、数据线进行充电
  ▸ 充电时确保充电接口干燥清洁，无液体残留
  ▸ 充电过程发现异常发热（烫手）、异味、冒烟，立即停止充电
  ▸ 充电时禁止覆盖设备（如置于枕头下、被褥中）

【防水防潮】
  ▸ 本设备防水等级：IPX□（具体以产品参数为准）
  ▸防水条件：静态清水1米深度30分钟（以官方宣传为准）
  ▸盐水、肥皂水、果汁、咖啡等液体不在防水范围内
  ▸充电前必须确保接口干燥

【废弃电池处理】
  ▸ 废旧电池请送至指定回收点或交由专业机构处理
  ▸ 禁止焚烧废旧电池（可能爆炸）
  ▸ 禁止随意丢弃（污染环境）
```

```
    4. 清除手机蓝牙缓存：设置→应用→蓝牙→清除缓存
    5. 确认未超出同时连接设备数量限制
    6. 升级系统版本后重试

    5. 清除NFC缓存后重试
```

```
  1. 拨打官方客服/在App内申请
  2. 选择「到店维修」或「寄修」
  3. 到达服务中心出示延保凭证
  4. 符合条件直接维修，无需付费
  5. 不符合条件（如人为损坏）则按标准付费
```
